How to Select the Latest Coupon Using ROW_NUMBER() in Oracle SQL

Learn how to use the ROW_NUMBER() window function to find the latest started coupon period for each instrument, with a practical Oracle SQL example.

About this tutorial

Return the latest coupon per instrument

This tutorial ranks coupon records within each instrument and returns the row with the most recent period start date before the current date.

The key technique is the ROW_NUMBER() analytic function with PARTITION BY and ORDER BY, a pattern that is useful far beyond coupon data.

01

Partition by instrument

Create a separate ranking sequence for each instrument.

02

Order the coupon records

Define which coupon row should be treated as the latest or current one.

03

Keep one row

Filter the ranked result to rn = 1 and return a single coupon per instrument.

How ROW_NUMBER() works in Oracle SQL

ROW_NUMBER() is an Oracle SQL analytic (window) function that assigns a unique sequential number to rows in a defined order. Unlike a regular GROUP BY aggregation, it can rank rows while preserving their individual columns.

Understanding PARTITION BY and ORDER BY

PARTITION BY c.instrument_id restarts the numbering for each instrument. ORDER BY c.period_start_date DESC places the most recently started coupon period first, giving it row number 1. The query first excludes future coupon periods with c.period_start_date < SYSDATE.

Practical example: find the latest coupon per instrument

The following Oracle SQL query uses the same logic as the downloadable tutorial file:

SELECT *
FROM (
    SELECT
        ROW_NUMBER() OVER (
            PARTITION BY c.instrument_id
            ORDER BY c.period_start_date DESC
        ) AS rn,
        i.instrument_name,
        i.isin,
        c.period_start_date,
        c.coupon_rate
    FROM glf.coupon c
    LEFT JOIN glf.instrument i
        ON i.instrument_id = c.instrument_id
    WHERE c.period_start_date < SYSDATE
)
WHERE rn = 1;

The inner query ranks eligible coupon records separately for each instrument. The outer query filters to rn = 1, returning one row per instrument with an eligible coupon period.

Important: This finds the latest coupon period that has started, not necessarily an actively valid period. To verify that a coupon is currently active, you would also need an appropriate period-end condition. If two rows have the same start date, add a stable tie-breaker to ORDER BY for deterministic results.

Frequently asked questions

What is the difference between ROW_NUMBER() and RANK()?

ROW_NUMBER() assigns a different number to every row, even when ordering values tie. RANK() gives tied rows the same rank and can skip subsequent rank numbers. For exactly one result per instrument, ROW_NUMBER() is often convenient.

Why use PARTITION BY in ROW_NUMBER()?

Without PARTITION BY, Oracle numbers rows across the entire result set. Partitioning by instrument gives each instrument its own sequence starting at 1.

Can this technique be used outside finance?

Yes. The same pattern can select the latest order, status update, price, or other dated record for each entity.
